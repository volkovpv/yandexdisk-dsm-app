# Аудит верхнего уровня проекта

Описание файлов и папок первого уровня. Отсортировано: сначала папки, затем файлы;
внутри каждого блока — по имени (записи на символы первыми).

| Тип | Название | Короткое описание |
|-----|----------|-------------------|
| папка | `.claude/` | Локальные настройки Claude Code (`settings.local.json`). |
| папка | `.git/` | Служебные данные системы контроля версий Git (история, ветки). |
| папка | `.github/` | Настройки GitHub: CI-воркфлоу (сборка/тесты/релиз) и список ответственных (CODEOWNERS). |
| папка | `.idea/` | Служебные настройки проекта для IDE JetBrains. |
| папка | `design/` | Материалы по дизайну: спецификация, бриф по UI и прототип интерфейса. |
| папка | `docs/` | Вся документация проекта (гайдлайны, рабочие процессы, планы, тесты). |
| папка | `downloads/` | Кэш скачанных бинарников rclone (ARM64/amd64) и их контрольные суммы для упаковки. |
| папка | `spk/` | Исходное дерево самого DSM-пакета: INFO, иконки, скрипты, конфиги, common.sh. |
| папка | `test/` | Герметичные тесты, проверки покрытия/воспроизводимости/контрактов и мутационный гейт. |
| файл | `.gitattributes` | Правила Git: заставляет скрипты пакета хранить LF-переводы строк (иначе ломается `#!/bin/sh` на DSM). |
| файл | `.gitignore` | Список файлов и папок, которые Git должен игнорировать (артефакты сборки, зависимости). |
| файл | `build.sh` | Главный скрипт сборки `.spk`-пакета (воспроизводимая упаковка). |
| файл | `build_notes.txt` | Заметки по сборке: целевое устройство, процессор, нюансы окружения. |
| файл | `CHANGELOG-ARM.md` | Журнал изменений по версиям пакета (единая линия для ARM и x86_64). |
| файл | `CLAUDE.md` | Канон проекта: правила, гейты и жёсткие инварианты для работы над пакетом. |
| файл | `NOTICE` | Юридическая справка о происхождении пакета и сопровождении. |
| файл | `README.md` | Руководство пользователя: как установить и настроить пакет на NAS. |
| файл | `RELEASE-INFO-ARM.txt` | Краткая карточка релиза (имя пакета, версия, метаданные) — синхронна с версией. |
| файл | `test-on-nas-functional.sh` | Скрипт функциональной проверки пакета прямо на реальном NAS. |
| файл | `test-on-nas-install.sh` | Скрипт проверки установки пакета на реальном NAS. |
