ARCHITECTURE (two builds from one source, same version)
----------------------------------------------------------------
Targets           : ARM64 / aarch64 / ARMv8   -> YandexDisk-ARM-<ver>.spk
                    x86_64 / amd64 (Intel/AMD) -> YandexDisk-x86_64-<ver>.spk
Sync engine       : rclone v1.74.3 (native linux-arm64 / linux-amd64, static)
Yandex backend    : rclone built-in "yandex" backend (two-way bisync)

Why rclone        : on ARM there is NO official `yandex-disk` CLI at all (it is
                    x86-only, no sources). The same rclone engine + DSM UI is
                    reused for the x86_64 build so both architectures share one
                    codebase and the no-SSH / no-daemon control surface; x86_64
                    users who prefer the official Yandex daemon still have it as
                    an alternative.
Build profile     : `bash build.sh` (arm64, default) or
                    `YD_ARCH=amd64 bash build.sh` (x86_64). Each profile pins its
                    own rclone zip+binary SHA256 and an ELF arch gate
                    (e_machine 183=AArch64 / 62=x86-64).

QUICK INSTALL
----------------------------------------------------------------
1. DSM -> Package Center -> Manual Install -> upload the .spk for your NAS CPU:
   YandexDisk-ARM-2.0.4.spk (ARM64) or YandexDisk-x86_64-2.0.4.spk (Intel/AMD).
   (On the warning about an unknown publisher, confirm install.)
2. After install, grant the system user `sc-yandexdisk` read/write on your
   sync shared folder (Control Panel -> Shared Folder -> Edit -> Permissions).
3. Open YandexDisk in DSM and configure everything in the UI (no SSH): click
   "Add folder", set the local folder + remote (yandexdisk:), then paste the
   OAuth token from `rclone authorize "yandex"` (run on a desktop with a
   browser). Click "Sync now" to run the first sync. See README.md.
4. Schedule periodic sync in DSM Task Scheduler with the command the UI shows
   (Control Panel -> Task Scheduler, user root):
       sudo -u sc-yandexdisk /usr/local/bin/yandex-disk sync
5. (Optional) Validate on the NAS over SSH:
       ./test-on-nas-install.sh
       ./test-on-nas-functional.sh

See README.md for the full model list, rclone setup, and DSM shared-folder
permission steps. Documentation map: docs/README.md.
