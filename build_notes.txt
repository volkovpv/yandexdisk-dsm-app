# Build notes — пакет Yandex Disk для Synology DSM (ARM64 + x86_64)

## Целевое устройство
- Модель:        Synology DS124
- Процессор:     Realtek RTD1619B
- Архитектура:   ARMv8 / aarch64 / ARM 64-bit
- Семейство DSM: rtd1619b

## Целевые ARM-платформы Synology (значение для поля arch= в spk/INFO)
rtd1619b rtd1296 armada37xx armada38x alpine4k

## Соответствие платформ и моделей (ориентир)
- rtd1619b   : DS124, DS223j, DS223, DS123 (Realtek RTD1619B, aarch64)
- rtd1296    : DS118, DS218, DS218play, DS418, DS420j (Realtek RTD1296, aarch64)
- armada37xx : DS120j, DS119j, DS220j (Marvell Armada 37xx, aarch64)
- armada38x  : DS116, DS216se, DS216j, RS217 (Marvell Armada 38x, 32-bit armv7 — см. примечание)
- alpine4k   : DS416, DS216, DS715 (Annapurna Labs Alpine, 32-bit armv7 — см. примечание)

## Примечание про разрядность
DS124 (rtd1619b) и rtd1296 — это 64-битные ARMv8 (aarch64): на них работает
нативный arm64-бинарник rclone. Платформы armada38x/alpine4k исторически
32-битные (armv7); arm64-бинарник на них не запустится. Они включены в arch=
для широты установки, но реально проверенная и работающая цель этого порта —
aarch64 (rtd1619b / rtd1296). Для строго 32-битных моделей потребуется отдельная
сборка rclone под linux-arm (armv7).

## Движок синхронизации: rclone (НЕ yandex-disk)
Официальный консольный клиент `yandex-disk` собирается Яндексом только под x86
(amd64/i386) — ARM-сборки не существует и исходников нет. Поэтому движком
синхронизации служит rclone (open-source, MIT) с нативной сборкой под
linux/arm64 и встроенным бэкендом Yandex Disk. Команда `yandex-disk` оставлена
как POSIX sh-обёртка поверх `rclone bisync`. Тот же движок используется и для
x86_64-сборки (см. ниже). Подробности и таблица различий с официальным клиентом —
в README.md, раздел «Почему rclone, а не официальный клиент».

## Источник бинарника rclone (две архитектуры)
build.sh докачивает официальный релиз rclone и сверяет SHA-256 (отдельно zip и
распакованного бинарника); сам бинарник в git НЕ хранится (раздаётся как
GitHub Release asset). Версия одна — v1.74.3, архитектура выбирается через YD_ARCH:
  arm64 (по умолчанию):  rclone-v1.74.3-linux-arm64.zip   (ELF e_machine 183)
  amd64 (YD_ARCH=amd64): rclone-v1.74.3-linux-amd64.zip    (ELF e_machine 62)
  база URL:              https://downloads.rclone.org/v1.74.3/
Свои RCLONE_ZIP_SHA256 / RCLONE_BIN_SHA256 для каждого профиля и шаги сборки
заданы в build.sh; .spk (YandexDisk-ARM-* / YandexDisk-x86_64-*) собирается
воспроизводимо байт-в-байт (pinned mtime + gzip -n). См. README.md, «Сборка пакета».
